# API de Consulta de Capitais

Aplicação em Node.js, TypeScript e Express para consulta de capitais de estados brasileiros.

## Como executar

1. Instalar dependências:
   ```bash
   npm install

2. Executar o servidor:
   npx tsx src/index.ts

3. Endpoint:
   GET /estados/:sigla: Retorna a capital correspondente à sigla informada (ex: /estados/SP).
